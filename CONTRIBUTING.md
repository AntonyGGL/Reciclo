# Contribuir a ReCiclo

Gracias por ayudar a mejorar ReCiclo.

## Flujo recomendado

1. Crea un fork del repositorio.
2. Abre una rama con un nombre descriptivo, por ejemplo `feat/nuevo-residuo`.
3. Realiza cambios pequeños y enfocados.
4. Abre el proyecto con Unity `6000.3.24f1` y comprueba las tres escenas principales.
5. Confirma que los archivos `.meta` de Unity acompañan a cada recurso nuevo.
6. Envía un pull request explicando el cambio y cómo se verificó.

## Convenciones

- Código C# legible y nombres coherentes con los sistemas existentes.
- No incluir las carpetas `Library`, `Temp`, `Logs`, `Build` o `UserSettings`.
- No añadir escenas de recuperación ni copias locales.
- Comprimir y optimizar imágenes y audio antes de incorporarlos.
- Documentar el origen y la licencia de cualquier recurso de terceros.

## Reportar problemas

Incluye la versión de Unity, la escena afectada, pasos para reproducir el problema y, cuando sea posible, una captura o video.
